# Ask-The-Human
Part Two of the Pi Extension


### Desired Inputs:
| Requirements | Explanation |
|---|---|
| Question | Ask the user one question for a single decision |
| Reason | Short explanation of why the choice matters |
| Options | Two or three choices with tradeoffs | 
| Recommendation | Optional; The preferred option |

### Result Status
| Status | Explanation | 
|---|---|
| Answered | The user's custom response or the chosen prompt |
| Cancelled | The user submits an empty custom response or cancels the interaction |
| Unavailable | The interaction with the user cannot be completed |
